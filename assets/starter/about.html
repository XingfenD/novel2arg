关于此项目

《一句话：这是什么》——一个把悬疑小说改编成的多页静态解谜网站。表面是一家再普通不过的机构网站， 公告、名录、检索结果都在该在的地方；线索埋在它们里面，答案要从字里行间推出来。

它源于什么

本项目由 novel2arg 生成——一个把悬疑 / 推理小说改编成“伪装成真实网站的解谜游戏”（ARG-lite）的 agent 技能，工作流八步：小说拆解 → 容器与模块选择 → 游戏设计文档 → 触达链分析 → 谜题设计分析 → 脚手架 → 实现 → 自检。技能仓库：github.com/XingfenD/novel2arg。

它是怎么搭起来的

纯静态，没有构建步骤：一篇一页的 HTML、本地 vendored 的 Alpine v3、零依赖的 Node 检查工具。 本地运行与检查命令见 README.md；设计文档在 docs/ 下—— system-profile.md、gdd.md、reachability.md、 puzzle-audit.md、self-check.md。

边界

改编有版权的小说需要权利人授权；本站内容不得用于钓鱼、冒充真实机构或诽谤。
