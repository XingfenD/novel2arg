- Componentize the graph viewer into a tree and emit it as a self-contained folder. `assets/viewer/` is no longer ten flat files: `graph-viewer.html` is the shell (three `x-data` regions — toolbar / canvas / rail), `css/base.css` + `css/canvas.css` carry the styles, `js/lib/{dom,legend,layout,store}.js` hold the shared layer (helpers, the kind legend, the pure layout geometry, and the one `Alpine.store('graph')`), and `js/{canvas,rail,toolbar}.js` are the region components — the canvas stays imperative (300+ edges rebuild faster built than bound) and owns its view transform in module scope, so a pan can never feed back into a rebuild and drop the selection. Reading a big graph keeps a trackpad-first view model — a two-finger swipe or a mouse wheel pans the canvas, only a pinch (which every browser delivers as ctrl+wheel) zooms at the cursor, with drag-pan and `+ / − / 复位` controls beside it — plus hover that dims everything but the hovered page's one hop, hop and supply counts on the node cards, and the problems list grouped by type with counts — click one to center, select, and pulse its node. The layout reads as layers instead of hair: routing moved into the pure layout core (`edgePath`, behavior-tested in node) — same-rank edges arc through the gap above their rank, and back edges leave the card grid for a right-margin bus, one lane per target, so the orphan layer's 130 upward nav edges stop crossing every intermediate rank; card lines are clipped to the width left of the corner stamps (the second line used to run under the M7 docket), and a nav bar's link to the current page is no longer drawn as a self-edge. Hovering no longer flickers when sweeping across cards: the dim clear fires only when the pointer leaves the canvas, never per node — a node-level leave flashed the whole graph bright at every card boundary, and a pause in the gutter between two cards defeated even a one-frame defer. A minimap sits in the canvas's bottom-right corner: the whole graph as a dot matrix (ink, with the entry green, gates red and unreachable pages stamp red) and the current viewport as a hairline blue rectangle — click or drag it to teleport the view centre, it follows every pan and zoom for four attribute writes a frame, hides itself when the viewport already covers the graph (the fit state) and on phones. Because the vendored CDN build auto-starts in a `queueMicrotask` right after its own script tag, the runtime loads LAST and every registration queues on the `alpine:init` event it dispatches inside `start()`, before the DOM walk — a missing runtime shows a red banner instead of a blank page. `site-graph.mjs` emits the whole tree into `docs/site-graph/` (JSON injected into `index.html`, the project's vendored Alpine copied into the artifact's own `js/vendor/alpine.js`, the agent-facing `docs/site-graph.json` beside the folder), so the artifact is one folder that opens from any server root or `file://`; `emit()` is the single writer for CLI and self-test, and the self-test now asserts every tree ref resolves inside the artifact, every js parses, and behavior-tests the pure layout core in node (entry origin, hop ranks, orphan rank, chrome filtering). The `.gitignore` template's two `docs/site-graph.*` lines collapse to the glob `docs/site-graph*` — the previous flat css/js artifacts were never ignored and would have been committed into projects.
